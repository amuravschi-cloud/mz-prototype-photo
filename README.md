# Metalica Zuev — прототип сайта, фото-версия

Как тёмная версия (mz-prototype-dark), но первый экран — фотография вместо 3D, с лёгким эффектом глубины
«как обои на iPhone»: фото сдвигается и чуть поворачивается за мышью (на телефоне — от наклона),
текст смещается в обратную сторону, при прокрутке фото уходит медленнее страницы.

Тексты, данные каталога и логика — без изменений из [mz-prototype](https://github.com/amuravschi-cloud/mz-prototype).

- `index.html` — собранная страница (генерируется, руками не править)
- `img/hero-photo.webp` — фото первого экрана
- `src/parallax.js` — эффект глубины (сила: MOVE, TILT, TEXT в начале файла)
- `src/style.css` — стили; `src/build.py` — сборка из `../mz-prototype-src/index.html`

Пересобрать: `python3 src/build.py`
